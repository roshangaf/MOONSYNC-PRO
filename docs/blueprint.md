# **App Name**: PerformaFlow

## Core Features:

- User and Department Management: Allow administrators to create user accounts, define roles (e.g., Marketing, Technician, Admin, Finance), and assign users to specific departments.
- Task Creation and Listing Portal: Marketers can create new job tasks, provide detailed descriptions, and assign initial priorities. All staff can view a comprehensive list of tasks relevant to their role.
- Manual Task Assignment: Administration can manually assign tasks to technicians, taking into account basic workload visibility (e.g., number of open tasks per technician).
- Technician Time Logging: Technicians can accurately log the start and end times for each task they are assigned, providing data for performance analysis.
- AI-Powered Task Detail Expansion: Utilize an AI tool to suggest sub-tasks, potential steps, or refine descriptions for new tasks created by marketers, based on task keywords or historical data.
- Performance Overview Dashboard: Provide a basic dashboard for department heads and administration to view staff performance metrics, such as tasks completed and average time per task for technicians.
- User Authentication and Role-Based Access: Secure user login with distinct access levels and permissions for each department role to ensure data integrity and privacy.

## Style Guidelines:

- The application will utilize a light color scheme to promote clarity and reduce eye strain for an ERP system. This approach emphasizes readability and a professional, modern aesthetic.
- Primary color: #2942A3. A deep, professional blue representing reliability and depth, providing a solid foundation for interactive elements and key headings. This ensures clear contrast with lighter backgrounds without being overly stark.
- Background color: #EDF0F7. A very light, desaturated blue derived from the primary hue. This light and airy backdrop supports the application's clean design, ensuring that content remains the focal point while maintaining a subtle brand presence.
- Accent color: #45B1E8. A vibrant yet controlled cyan-blue. This accent will be strategically used for calls to action, active states, and critical highlights, providing clear visual cues and an engaging contrast with the primary and background colors.
- All text, including headlines and body content, will use 'Inter' (sans-serif). This choice ensures a modern, clean, and highly readable experience, ideal for an information-dense ERP application.
- Adopt a minimalist, line-icon style for all interface elements. This maintains visual consistency, enhances clarity, and contributes to the app's professional and modern aesthetic, ensuring icons are easily recognizable across all departments.
- The layout will be structured and dashboard-centric, featuring clear, intuitive organization of information with distinct sections for tasks, performance metrics, and departmental overviews. This promotes efficiency and easy navigation within the system.
- Implement subtle, brief micro-animations for user feedback, such as form submissions, task assignments, and data updates. These animations will be designed to enhance user experience by providing clear confirmation of actions without distracting from core tasks.
